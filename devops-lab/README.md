Independent, AI-assisted engineering lab by Anukumar Bendi.
Not employer code or a production deployment.

Includes:
- Modular Terraform Azure foundation
- Optional private AKS and Helm workload
- Reusable Azure DevOps validation pipeline
- Dry-run-first Entra group-membership automation

Locally validated:
- Terraform initialization and validation
- Nine mocked identity tests
- Helm lint and rendering

Not yet validated:

- Live Entra operations
- Kubernetes runtime behavior
- Azure DevOps hosted execution
